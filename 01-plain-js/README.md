# Plain JS

No frameworks, no build system, just vanilla js using type module, no AI of course. Browsers supported this back from 2015 with ES6. Though major support only arrived later in 2017, we're now in 2026.

No backend, php is used so that we can run `php -S localhost:8080` to serve easily.

It took me 1 hour and 20 minutes without preparation, i just went straight ahead into coding it.
